# Station concepts

Built-in image_gen mode. Two layout previews adapted into runtime modules in railway-v4. The final layout uses the same square gameplay grid; exact geometry differs to preserve maze access. Preserve existing 48px gameplay grid when adapting modules. Departure and arrival share teal/brass railway styling; final train sprites must use one consistent vehicle model.

## Departure prompt
Use case: stylized-concept. Draw a production-minded 2D Japanese fantasy RPG station layout preview for Chari Dungeon ZERO, DEPARTURE STATION near dungeon entrance. Orthographic three-quarter top-down like classic top-down RPG map (NOT isometric diamond tiles, no vanishing-point perspective), square aligned walkable tiles, finely painted pixel-art aesthetic with crisp rich colors. A substantial proper railway station built from warm cream masonry, dark teal roof canopy supported by iron columns, brass trims, wooden benches, timetable board, clock, luggage cart, warm lanterns. One narrow three-tile long passage enters from TOP CENTER from dungeon entrance, passes an obvious brass ticket gate then opens into a small tiled concourse on left and boarding platform. A single railway runs VERTICALLY along RIGHT side, continuous parallel rails and sleepers with straight exits top and bottom. A small handsome dark teal and brass fantasy tram parked at platform, clear doors facing platform, vehicle must fit rails. A clearly visible cyan glowing square boarding panel on platform next to tram door. Platform is raised, clean edge stripe, guardrails only where they don't block access. Add one small adventurer for scale, height about 1.5 tiles; platform is 3 tiles wide and 10 tiles long. Rectangular station overall about 13x16 tiles. Dark cavern surrounding solid retaining walls, but station feels like a real station not reused dungeon corridor blocks. Keep all navigation obvious, no obstructing props on walking route, no UI panels, no text labels, no logos. Show complete station from above, no cropping, beautiful implementable arrangement built from modular floors/walls/canopy/props. This is layout concept art, not a distant cinematic.

## Arrival prompt
Use case: stylized-concept. Draw a production-minded 2D Japanese fantasy RPG station layout preview for Chari Dungeon ZERO, ARRIVAL STATION beside a boss area. Orthographic three-quarter top-down classic RPG map, square aligned tiles, NOT isometric diamond grid, no vanishing-point perspective. Fine painted pixel art, crisp rich colors. Substantial proper railway station: blue-gray dressed masonry, dark teal roof canopy on iron columns, brass trim, benches, station clock, lanterns, signboard with no readable letters. It belongs to same railway as a warm cream/teal/brass departure station, but this is a more solemn terminal near purple crystal boss gates. One railway runs VERTICALLY along LEFT side with correctly continuous parallel rails and sleepers entering from bottom; end buffer near top. Same small handsome dark teal and brass tram parked along platform, doors toward RIGHT platform, wagon correctly aligned on rails. Raised boarding platform is 3 tiles wide and 10 tiles long, cyan glowing square boarding panel next to carriage doorway also permits return trip. Clear concourse and open brass exit ticket gate leads through a SHORT passage toward TOP RIGHT where a large sealed purple-crystal boss doorway stands outside the station. Boss room itself not shown. Preserve strong separation station vs boss architecture; do not turn entire station purple. Dark cavern and rocky retaining perimeter. One small adventurer about 1.5 tiles tall for scale, all prop sizes consistent. Rectangular station about 13x16 tiles, complete station visible, no cropping. Clear unobstructed navigation, modular stone floors/canopy/walls/railings. No UI, no overlay text, no logos. Beautiful practical game map layout, not a cinematic illustration.
