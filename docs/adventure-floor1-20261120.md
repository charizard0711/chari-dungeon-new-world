# 精霊樹と結晶門の遺跡

町の「冒険部屋」または西側の掲示板から、1〜4人の保存される冒険部屋を作成・再開する。合言葉は任意。1キャラにつき参加中の冒険は1つ。

## 一層目

添付された案Cを参考に88×34マス、13エリアを接続した。中央の精霊樹、泉、旅商人、転送台、苔むした祭壇、石の守護者、紫糸の巣、滝の橋、宝物庫、罠、結晶門の聖域を回る。全体絵を背景に貼る方式ではなく、衝突判定のあるマスと再利用可能なパーツで構成する。

琥珀鍵の石守を倒すと琥珀鍵（近道・宝物庫）、紫鍵の織り手を倒すと紫鍵（ボス区画）を部屋全体で取得する。回復設備は近くの敵を倒して利用。旅商人はポーション20G。宝箱・罠の停止状態も保存される。

新ボスは「結晶門の守護者ヴェスパー」。結晶落下と十字の裂光を交互に予告し、HP半分以下で威力が上がる。敵や武器スキルの数値・効果は初期調整用。既存武器の見た目と攻撃アニメーションを再利用するが、オンラインの敵への一部スキル効果は暫定実装。

ボス撃破で階段が出現し、現在のメンバー各自に一度だけ300Gと回復ポーションを付与する。**今回の戦闘コンテンツは1層のみ。2層は安全な入口だけで、次のフロアは未実装。** 最初の一人が進むと2層入口も共通の合流先になる。

## 保存と合流

敵HP・撃破、鍵、開封、部屋専用の落とし物、チャット100行、到達済みエリア、階段をDBで保持する。全員が退出した間は敵の進行を止め、再開時に経過時間分の攻撃を発生させない。ホスト退室でも部屋は残る。敵の近くからの即時転送は禁止。行動不能になると所持品を失わず入口でHP50に回復する。

「転送・部屋」から町へ帰還、前回位置で再開、誰かが到達したエリアに合流できる。クリア後は明示的に冒険を終了して次の部屋を作成できる。未クリアの断念は作成者が全員退出後に行う。

部屋の状態と所持品の更新は認証済みRPCからのみ行う。部屋の合言葉ハッシュと内部テーブルはクライアントへ公開しない。町のドロップ・チャットとは分離する。

## 新規画像

生成方法は **組み込みimage_gen**（CLI不使用）。透明背景の生成結果を保存し、アルファを保ったまま切り抜き・サイズ調整・アトラス化した。

- 原画：`art/adventure-floor1-v1/boss.png`、`props.png`
- 指示セット：`art/adventure-floor1-v1/prompts.json`
- 実行時：`public/assets/online/adventure-v1/boss.webp`、`props.webp`
- 再パック：`node scripts/prepare-adventure-art.mjs`
- Propsの順序：精霊樹、蒼い転送台、鍵付き門、紫水晶、地下水の泉、宝箱、階段、赤い罠の祭壇、掲示板。

## 検証

- `npm run test:adventure`：鍵の前後の経路、到達地点、クライアントとSQLマップの一致、4人制限、合言葉、他部屋との分離、中断保存、装備の個体ID・色違い・耐久値、金貨、開封・商人・罠、予告攻撃の命中と回避、報酬の重複防止、階段・合流・権限。
- `npm run test:town`、`npm run test:town:equipment`：既存の町、倉庫、装備、フレンドなどの回帰確認。
- `npm run build`。
- ブラウザーは `?mute=1` / `noAudio=true`。ローカルPGliteの架空キャラで作成・移動・帰還・再入場・右クリック攻撃・ボス撃破・階段を確認。
- Supabaseに `202611200005_online_adventures.sql` を適用。公開前の最終RPC修正も反映する。

原作ソロのリポジトリーと公開先は変更しない。
