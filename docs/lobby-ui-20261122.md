# Moonlit lobby UI

Implements the approved silver/cyan/violet two-character reference with independently generated background and transparent silver logo. Existing authentication, CAPTCHA, email confirmation, creation and join RPCs remain intact. Character portraits use actual equipped visuals. The selected character can enter through the card or the bottom confirmation button. Only the existing two character slots are displayed. The shop navigation is disabled with a town-merchant explanation; home and settings work.

Development preview: /lobby-check.html?mute=1 (fixture characters), add &login=1 for the real login form without submitting credentials. Preview character creation/entry is prevented from calling the backend. The page is not included in production build inputs. Tests: TypeScript/build and muted browser checks of character cards, creation/back navigation, settings and login/signup email preservation.

Art prompts and sources: public/assets/new-world/lobby-v2-ASSETS.txt.
