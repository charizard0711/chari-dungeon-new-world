# Panel audio v1

Original synthesized sounds; no third-party samples or quoted melodies. 48 kHz stereo, 24-bit PCM WAV. Rebuild with `py scripts/build-panel-sounds.py` (NumPy required).

heal.wav is the exact approved preview 01-rpg-heal.wav. SHA256: 85520f8e8e9afec53315dcef9723b48c2e186bb7d0157c7c698dea71d830fbe2.

Attack/defense up use ascending rounded triangle/pulse tones. Down variants descend. Paralysis is a short alternating stutter. All variants share soft edges and a subtle stereo delay.
